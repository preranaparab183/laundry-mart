# Laundry Wallah / Laundry Mart

A foundational HTML webpage created for **Laundry Wallah / Laundry Mart** (TuteDude MERN Stack - Task 2: HTML). This project showcases a clean, structured layout for a premier laundry service, highlighting its offerings, pricing, and a booking interface.

## Problem Statement
Laundry Wallah / Laundry Mart aims to enhance its online presence through a user-friendly HTML webpage. The page serves as a digital storefront that introduces the brand, lists available laundry services, displays transparent pricing, and allows customers to easily book a service.

##  Features & Sections
The webpage is structured into the following core sections:

1. **Header Section:** 
   - Displays a welcoming main heading: *"Welcome to Laundry Wallah / Laundry Mart."*
2. **About Section:** 
   - Provides a brief introductory paragraph (5-8 lines) detailing the mission and quality of Laundry Wallah / Laundry Mart.
3. **Image Section:** 
   - Features a relevant laundry service image to enhance visual appeal.
4. **Services Section:** 
   - Includes an *"Our Services"* heading accompanied by a structured list of offerings (e.g., Washing and Drying, Ironing and Folding, Dry Cleaning, Stain Removal, Express Services, Special Garment Care).
5. **Price List Section:** 
   - Includes a *"Price List"* heading and a bordered HTML <table> mapping services to their respective prices (e.g., Washing and Drying - Rs 10.00, Ironing and Folding - Rs 5.00).
6. **Book Now Section:** 
   - Includes a *"Book Now"* heading and an interactive HTML <form> with required input fields for the user's **Name**, **Email**, and **Phone Number**, along with a **Submit** button.
7. **Footer Section:** 
   - Contains contact details: *"Contact us at: info@laundrymart.com."*

##  Technologies Used
* **HTML5** (Semantic tags, lists, tables, forms, and input validation)

##  How to Run Locally
1. Clone or download this repository to your local machine.
2. Navigate to the project folder.
3. Double-click on 'index.html' (or right-click and select **Open with** your preferred web browser) to view the webpage.
